IP Public adalah ip yang bisa digunakan di jaringan internet. Ciri utama IP Public adalah bisa di akses dimanapun dan tidak boleh ada dua perangkat yang menggunakan alamat IP Public yang sama pada waktu yang bersamaan.

IP Private adalah ip dalam jaringan lokal. IP Private hanya bisa diakses di jaringan lokal.

Range IP Private adalah sekumpulan alamat IPv4 yang dicadangkan khusus untuk jaringan lokal (LAN) dan tidak dapat diakses langsung oleh internet publik.

Range IP Private (IPv4):
<p>Kelas A: 10.0.0.0 - 10.255.255.255</p>
<p>Kelas B: 172.16.0.0 - 172.31.255.255</p>
<p>Kelas C: 192.168.0.0 - 192.168.255.255</p>
<p>Yang tidak termasuk ke dalam Range IP Private merupakan IP Public.</p>

Kesimpulan:

IP Address terbagi menjadi IP Public dan IP Private. IP Public digunakan untuk terhubung ke internet, sedangkan IP Private digunakan untuk jaringan lokal.
