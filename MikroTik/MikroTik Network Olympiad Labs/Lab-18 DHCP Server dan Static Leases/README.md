Langkah-langkah

1). Login ke MikroTik menggunakan WinBox

2). Konfigurasi IP Address:

Buka menu IP>>Addresses

Klik + lalu tambahkan

Address: 192.168.10.1/24

Interface: ether2

3). Buka menu IP, klik DHCP Server, klik DHCP setup, pilih interface ether2 lalu klik next sampai selesai.

4). Membuat static lease
