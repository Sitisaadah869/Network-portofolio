Backup dan Restore pada MikroTik

Langkah-langkah:

1). Login ke MikroTik menggunakan Winbox

2). Buka Menu File, klik Backup

<p>Name: konfigurasi wlan1</p>
<p>Password: 12345</p>
<p>Klik Backup Config</p>
<P align="center">
<img width="600" alt="WhatsApp Image 2026-07-06 at 09 11 10" src="https://github.com/user-attachments/assets/168d5b69-4e50-479e-b37e-c8a429846f7b" /></P>

3). Reset Configuration
<p>System>>Reset Configuration</p>
<p>Ceklis: Do Not Backup, No Default Configuration</p>
<P align="center">
<img width="400" alt="WhatsApp Image 2026-07-06 at 09 11 10 (1)" src="https://github.com/user-attachments/assets/ac2d33e5-3fbe-4cba-9248-82ea01c55f79" /></P>

4). Login kembali ke MikroTik menggunakan Winbox

5). Buka menu File, klik file "konfigurasi wlan1" lalu klik Restore, masukan password 12345, lalu klik Restore
<P align="center">
<img width="600" alt="WhatsApp Image 2026-07-06 at 09 20 07" src="https://github.com/user-attachments/assets/e996d831-cfd1-470d-836d-162f3c2211e8" /></P>
6). Setelah Klik Restore akan kembali ke menu login winbox, login kembali ke MikroTik dengan Winbox
<P align="center">
<img width="600" alt="WhatsApp Image 2026-07-06 at 09 20 07 (1)" src="https://github.com/user-attachments/assets/21082808-8328-4cc0-bc71-1b7c03573212" /></P>

7). Setelah login konfigurasi sudah kembali sesuai dengan file backup.

Kesimpulan:

Bakup dan Restore MikroTik berfungsi untuk menyimpan serta mengembalikan konfigurasi router.
